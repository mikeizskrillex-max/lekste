# Seed data

- `ingredients_lt.csv` — стартовый каталог (~120 базовых продуктов). **Ожидается от владельца** до фазы 2; кладётся сюда без изменений. Поля `availability_*` в нём не проверены — их заполняет фаза 5 (`npm run ingredients:verify`, только Barbora и Rimi, см. `docs/decisions.md`).
- Остальные seed-файлы (демо-персоны, тестовые цены, тестовые пользователи) появятся в фазе 1.
